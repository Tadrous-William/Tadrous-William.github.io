# tadrous-william.github.io

Portfolio of **Tadrous William**, AI Engineer & Data Scientist: https://tadrous-william.github.io

Plain HTML, CSS and a little JavaScript, hosted on GitHub Pages.

- Edit the text in `tools/build_site.py`, then run `python tools/build_site.py` to rebuild the pages.
- `tools/make_images.py` converts project screenshots to WebP; `tools/make_icons.py` draws the favicons and the sharing image.
